# superintelligence-os.github.io

Web de SIOS (SuperIntelligenceOS): https://superintelligence-os.github.io/

- `index.html` (español) y `en.html` (inglés) se generan con `python3 web/generar.py`.
- `privacidad.html` y `privacy.html`: la política de privacidad.
- Todo es estático y se sirve desde aquí: sin fuentes, scripts ni analítica de terceros.

El código de SIOS está en https://github.com/superintelligence-os/superintelligence-os (AGPL-3.0).
